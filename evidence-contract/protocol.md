# Evidence-contract evaluation protocol

The expected outcomes and seven controls were frozen at `2026-11-07T03:47:36.441268Z`, before invoking the production checkers with mutated inputs. [Protocol provenance](protocol-freeze.json) records hashes of the original protocol, 86-row matrix, fixture manifest, and checker code at that time. The complete fixture manifest is retained outside this repository because it contains historical state paths, grants, Evidence blobs, and target references. The [public case matrix](evidence-contract-cases.csv) retains the test inputs, expected outcomes, stages, and reasons without those bytes. Public `EC-` test IDs preserve the route and sequence suffixes of the frozen private IDs.

Each route uses one author-audited positive control from its selected primary attempt: source S01/F1, ASAR A01/F1, ELF E01/F1, PE P02/F2, managed M03/F3, APK D01/F1, and host/WASM W01/F1. Twelve cases per route test valid intake, wrong target identity, valid citation, wrong answer digest, unknown Evidence reference, undelivered foreign reference, altered blob, out-of-range original coordinate, granted foreign-target blob, valid static gate, missing separately scheduled reviewer, and insufficient shared original locations. Two further source cases separate a valid but non-proving coordinate from an unsupported semantic inference. Expected outcomes are `accepted`, `rejected`, or `gap` at the named checker stage. Acceptance means that stage accepted its input; it does not mean a vulnerability is true.

The invoked production paths were `verify_target`, `Coordinator.verify_frozen`, `validate_citations`, `Coordinator.read_evidence`, and `Coordinator._static_confirmation`. The runner used a fresh isolated copy per case and compared canonical decision fields before and after. Target digests, Evidence-blob digests, and export-report digests are distinct identities. A passing gate yields `static_path` only. No model, vulnerable target, or PoC was run during this checker evaluation. Current-code results cannot establish the behavior of historical scan code revisions that were not recorded.
